One crypto/trading joke, under 200 characters. A comedy judge scores it on
setup and turn, a real laugh, truth to trading life, and a tight punchline
at the end.

## The joke

> I bought the dip. The dip bought my rent money.

47 characters. Setup ("I bought the dip") flips into the turn: the dip
bought something back — the rent money. True to every trader who watched a
"bargain" eat the budget for the month.

## Run

```sh
python3 main.py
```

Writes the joke to `/output/entry.txt` (UTF-8, 1–200 chars). No network,
no dependencies, stdlib only.
